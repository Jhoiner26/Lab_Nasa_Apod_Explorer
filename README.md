# Lab_Nasa_Apod_Explorer

🌌 Explorador APOD - NASA

Proyecto para el módulo de JavaScript y NPM en Generation Colombia. Construimos una página web que consume la API de la NASA para ver la Foto Astronómica del Día (APOD), buscar fotos por fecha y guardar tus favoritas.
